# Rework Autopsy Frontend

Next.js frontend for the Rework Autopsy prototype.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- daisyUI

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
npm run format
npm run format:check
```
